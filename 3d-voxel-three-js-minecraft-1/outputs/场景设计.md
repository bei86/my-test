# 体素古建院落场景设计

## 交付
单个 HTML 文件，内嵌 Three.js 与全部场景代码，无后端、无外部纹理、无需安装；桌面浏览器双击打开。附简短 README。SVG 无法满足真正的 Three.js 三维旋转场景，因此采用 HTML。

## 画面
六座建筑组成中轴对称院落：后方最大的重檐主殿、左右配殿、前方山门，以及左右两座五层宝塔。主殿使用金色琉璃瓦，其余屋顶采用青绿色瓦与金色脊饰。所有结构由方块拼接，屋面逐层收分并在檐角抬升，表达庑殿、歇山与攒尖形制。

主殿与配殿具有红墙、木色梁架、红柱、斗拱、格窗、石台基与台阶。山门设灯笼及一对体素石狮。中轴石板路贯通山门、开阔庭院与主殿。院落包含草地、松柏、围墙、石灯及对称景观，建筑之间保留明确通行空间。

## 观看与交互
页面加载即显示整个场景，初始为斜俯视全貌。鼠标拖动旋转，滚轮缩放；提供自动环绕开关、晨光/暮色切换、复位视角按钮。界面采用少量中文文字与紧凑控件，避免遮挡建筑。

## 技术与验证
纯 JavaScript + Three.js，体素按材质分组使用 InstancedMesh。使用定向光阴影、环境光、柔和雾与颜色管理；限制像素比和阴影贴图大小。窗口调整后更新相机与渲染尺寸。对不支持 WebGL 的浏览器显示中文提示。

实际验证包括单文件离线资源完整性、浏览器加载、全貌截图、交互与两种光照切换。性能目标为通常桌面环境下旋转达到 30fps，最终报告区分实际测量与目标，不承诺所有设备帧率。
