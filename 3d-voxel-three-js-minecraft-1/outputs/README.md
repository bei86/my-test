# 青阙 · Three.js 体素古建院落

## 直接观看

双击同目录的 **青阙·体素古建.html**，选择 Chrome、Edge 或 Firefox 打开。无需安装、无需后端、无需联网。Three.js、控制器、样式和全部程序化模型都已内嵌，文件约 523 KB。需要支持 WebGL 2 的浏览器。

也可观看已启动的本机预览：<http://127.0.0.1:5173/dist/index.html>。该地址仅在预览服务运行期间可用。

## 场景与交互

- 六座建筑：最大的重檐金瓦主殿、两座对称青瓦配殿、入口山门、两座五层宝塔。
- 中轴道路贯通山门、庭院和主殿。具有柱、斗拱、格窗、红灯笼、石狮、石台阶、围墙、双水池、松柏和花树。
- 鼠标左键拖动旋转，滚轮缩放，右键拖动平移；触屏单指旋转、双指缩放与平移。
- 控制栏提供环绕、晨昏、归位与建筑说明。键盘 R 归位、L 晨昏、空格环绕（按钮聚焦时遵循按钮键盘行为）。
- 建筑形制为体素艺术化表达，并非历史建筑精确测绘复原。

## 源码项目

项目位于 `voxel-palace/`，源代码和固定版本依赖均包含。另有不含 node_modules 的 `青阙-完整项目.zip`。

```text
voxel-palace/
  package.json / package-lock.json
  build.mjs             # 将 Three.js 与场景代码打包内联
  index.html            # Vite 开发入口
  src/
    main.js             # 程序化模型、实例化批次、相机与光照
    shell.html          # 中文界面
    style.css           # 响应式样式
  dist/index.html       # 构建后的单文件
  THIRD-PARTY-LICENSE.txt
```

Node.js 20.19+ 或 22.12+，在 `voxel-palace` 目录执行：

```powershell
npm install
npm run build
npm run dev
```

浏览器打开终端显示的地址，默认是 <http://127.0.0.1:5173>。

修改 `src` 后重新运行 `npm run build` 并刷新预览。构建同时输出 `dist/index.html` 与项目上一层的 `青阙·体素古建.html`。源码使用 ES 模块；可双击的是构建好的 HTML，而非源码入口。

- `npm run build` 成功；JavaScript 语法检查通过。
- 内置 Chromium 浏览器通过本机 HTTP 加载构建产物，首屏显示六座建筑完整全貌，控制台无警告或错误。

- 单文件静态检查确认没有外部脚本、外部样式、模型或纹理加载；交付 HTML 与已验证的 `dist/index.html` 字节一致。

## 实现说明

场景以共享 BoxGeometry 和三组按材质分类的 InstancedMesh 构造，不为每个方块创建独立 Mesh。屋面逐层收分，量化曲线与角部抬升形成瓦片飞檐。使用固定种子的颜色变化，确保每次加载场景相同。方向光软阴影、半球环境光、ACES 色调映射与像素比上限控制画面开销。无外部图像、字体或 CDN。
